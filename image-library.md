# Product Image Library

Curated stock image URLs for use in search demos. All images are from [Pexels](https://www.pexels.com) and are publicly accessible without authentication.

**URL format:** `https://images.pexels.com/photos/{ID}/pexels-photo-{ID}.jpeg?auto=compress&cs=tinysrgb&w=400&h=480&fit=crop`

> **Note:** Pexels CDN URLs are stable. If any return a 404, visit pexels.com, search the category, copy the photo ID from the URL, and substitute it.
