## Upgrade Path: Unsplash API

If you need a larger or more targeted image set, sign up for a free Unsplash Developer account and use the API:

```
GET https://api.unsplash.com/search/photos?query=running+shoes&per_page=10
Authorization: Client-ID YOUR_ACCESS_KEY
```

Replace the curated URLs in the product catalog with `urls.regular` or `urls.small` from the API response.
